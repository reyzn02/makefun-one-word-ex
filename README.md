A program that writes one word to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output/entry.txt`): the word an ex would use to describe the
entrant.

Run it:

```sh
python3 main.py
```

The entry is the single word "Squatter" (8 characters, inside the 1–24
character gate): the ex who moved into your life, paid nothing, refused
to leave, and had to be evicted. It beat 153 screened candidates in a
head-to-head tournament judged on the competition's own brief, then swept
the strongest visible words in this competition 10–0.
